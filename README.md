A static website for a fictional science museum, providing essential visitor information with a focus on clarity and accessibility.


## 📘 Description

ScienCity is a frontend project designed to simulate a museum information site. Built with semantic HTML and modular CSS, it delivers a clean, responsive layout that adapts seamlessly across devices. The site offers visitors an overview of current activities, location details, and opening hours.

- Activities Overview – Explore current and upcoming science-related events and exhibitions  
- Location Details – Clear directions and contact information  
- Opening Hours Section – Easy-to-read schedule for planning visits  
- Responsive Design – Optimized for mobile, tablet, and desktop  
- Clean Layout – Structured and accessible design using semantic HTML
